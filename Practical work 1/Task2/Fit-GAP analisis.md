
# 1 Список систем
## 1.1 ИС Алмазы
Тип ИС: существующая, внутренняя
**Функциональность**
1. Добавление функциональности для отбора алмазов для цифрового аукциона:
Требуется функциональность, чтобы предоставить возможность пользователям (сотрудникам компании) отбирать алмазы для дальнейшего выставления на онлайн-аукцион.
Функциональность должа позволять отобрать алмаз, присвоить ему идентификатор, внести контрольные даты оцифровки и продажи, чтобы выдержать сроки бизнес-процесса. Кроме того, функциональность должна позволять формировать ведомости для перевозки и для подготовки договоров купли-продажи по итогу аукциона в ИС Бухгалтерия.
2. Добавление функциональности для выгрузки отбора алмазов в файл:
После отбора алмазов и формирования плана перемещений и продажи данные должны из ИС Алмазы попадать в ИС Логистика. На начальном этапе это будет выполняться вручную, но в дальнейшем необходимо автоматизировать процесс, чтобы минимизировать человеческий фактор.
**Интеграции**
1. ИС «Алмазы» → ИС «Логистика»:            планирование и перевозка алмазов (существующая).
2. Подключение к брокеру сообщений:        чтение и отправка данных в/из шину/ы (новая);

## 1.2 ИС Логистика
Тип ИС: существующая, внутренняя
**Функциональность**
1. Добавление функциональности для перевозки алмазов в пункты назначения:
Требуется функциональность, чтобы предоставить возможность пользователям (сотрудникам компании) формировать документацию для отправки алмазов перевозчиком.
2. Формирование актов выполненных работ:
Требуется функциональность, чтобы предоставить возможность пользователям (сотрудникам компании) формировать документацию по фактически выполненным перевозкам в ИС Бухгалтерия для оплаты и документарного закрытия выполненных работ.
**Интеграции**
1. ИС «Логистика» → ИС «Бухгалтерия»:      актирование и оплата услуг транспортной компании (существующая).
2. ИС «Логистика» → ИС «Алмазы»:           планирование и перевозка алмазов (существующая).
3. Подключение к брокеру сообщений:        чтение и отправка данных в/из шину/ы (новая);

## 1.3 ИС Бухгалтерия
Тип ИС: существующая, внутренняя
**Функциональность**
1. Добавление функциональности для импорта актов в виде файлов:
Необходимо реализовать функциональность получения файлов актов выполенных работ от ИС Логистика и ИС Лаборатория для взаиморасчетов и документооборота.
2. Добавление функциональности для ведения контрактов:
Необходимо реализовать функциональность ведения контрактов с перевозчиком, лабораторией и покупателями алмазов.
**Интеграции**
1. ИС «Бухгалтерия» → ИС «Лаборатория»:    актирование и оплата услуг лаборатории (новая).
2. ИС «Бухгалтерия» → ИС «Логистика»:      актирование и оплата услуг транспортной компании (существующая).
3. Подключение к брокеру сообщений:        чтение и отправка данных в/из шину/ы (новая);

## 1.4 ИС Лаборатория
Тип ИС: новая, внешняя
**Функциональность**
1. Добавление функциональности для импорта файла с отобранными алмазами:
Необходимо реализовать функциональность чтения файла с перечнем алмазов для оцифровки.
2. Добавление функциональности для экспорта файла с выполненными работами по оцифровке:
Необходимо реализовать функциональность для отправки файла с результатами выполенных работ. На основании такой документации бухгалтерия может формировать акты выполненных работ.
**Интеграции**
1. ИС «Лаборатория» → ИС «Аукцион»:        передача описания алмазов (новая).
2. ИС «Лаборатория» → ИС «Бухгалтерия»:    актирование и оплата услуг лаборатории (новая).
3. Подключение к брокеру сообщений:        чтение и отправка данных в/из шину/ы (новая);

**Функциональность**

**Интеграции**
1. ИС «Аукцион» → ИС «Лаборатория»:        получение описания алмазов (новая).
2. Подключение к брокеру сообщений:        чтение и отправка данных в/из шину/ы (новая);
