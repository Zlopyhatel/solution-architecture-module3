# Введение

## Цель документа
Данный документ описывает целевое состояние архитектуры решения для компании «Diamond Universe», позволяющее полностью автоматизировать процессы, включающие в себя:
1. Получение алмазов в офисе после добычи;
2. Транспортировку и оцифровку алмазов;
3. Реализацию алмазов посредством онлайн-торгов;
4. Доставку алмазов конечному покупателю.
Ключевое ограничение реализации проекта (на момент подготовки документации): срок реализации - два месяца.
Ключевое требование: запуск проекта, пусть даже в полуручном режиме.

## Область применения: на какие части системы или подразделения распространяется решение.
Данное решение охватывает подразделения:
1. Офис, где проводятся офлайн-аукционы, сортируются и хранятся алмазы.
2. Внешняя лаборатория, которая проводит оцифровку камней.
3. Специальный перевозчик (кто может транспортировать алмазы по стране и за границу).

Для функционирования решения планируется использовать существующие ИСы:
1. Основной бизнес: информационные системы (ИС) «Алмазы» и «Аукцион».
2. Внутренние обеспечивающие системы: ИС «Бухгалтерия» и ИС «Логистика».
3. Внешние обеспечивающие системы: ИС «Лаборатория» (новая) и облачные сервисы. 
## Глоссарий: определение ключевых терминов, основные объекты данных, которые будут обрабатываться.

# Бизнес-контекст и цели
## Задача 
Организовать цифровой канал сбыта для «Diamond Universe».

## Решение
Используя существующие и новые ИС, автоматизировать и модифицировать существующий бизнес-процесс с дальнейшим переходом в более глубокую автоматизацию и интеграцию и уложиться в сроки реализации проекта.
Обязательные требования к компонентам: минимальная доработка и изменение имеющихся ИС, чтобы сохранить сроки реализации.

## Описание процесса
Для реализации цели предлагается процесс, состоящий из следующих шагов:
1. Отбор алмазов для продажи онлайн в центральном офисе.
2. Перевозка алмазов в лабораторию, их оцифровка, и возврат обратно в офис. 
3. Публикация данных для покупателей, на основе которых будут приниматься решения. 
4. Проведение онлайн-аукциона. 
5. Отправка камней победителям торгов из офиса.
